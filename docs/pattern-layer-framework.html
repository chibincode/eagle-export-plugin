Pattern Layer Framework

把 Eagle 里的 section 灵感，从“截图好看”拆成可检索的设计模式。它不替代现有 taxonomy，而是在经典分类之上记录意图、结构、素材策略和相似性签名。

Classic taxonomy stays. Pattern Layer explains the why and shape.

现有 taxonomy 负责“它属于什么分类”。Pattern Layer 负责“这个 section 用什么认知路径表达内容”。

1

Evidence Layer

先记录可见文字、布局、组件、颜色、视觉记忆点。所有 pattern 判断必须从截图证据出发。

2

Pattern Layer

再判断 message_intent、structure_pattern、layout_skeleton 和 content_style。截图里的具体画面线索统一进入 evidence。

3

Discovery Layer

最后生成 similarity signature，让未来可以按设计意图找相似 section，而不是只靠标签筛选。

Decision Stack

这个顺序很关键：不要先问“icon-led 还是 screenshot-led”。先判断 section 要帮用户理解什么，再选择结构和素材。

section_type
经典模块类别，例如 Hero / Features / Pricing / CTA。
message_intent
为什么存在：这个 section 要完成的认知任务，例如解释流程、建立信任、推动行动。
structure_pattern
可复用结构形状，例如等权卡片网格、横向步骤流、居中行动条带。
layout_skeleton
骨架，例如 centered、split、grid、bento、timeline、carousel。
content_style
媒体 / 素材策略，例如 screenshot-led、icon-led、photo-led、data-led。

Pattern Profile Fields

每张 section 图的最终记录字段。它们是未来 Smart Discovery 的原料，不是直接暴露给用户的一排 filters。

section_type沿用现有 UIBook taxonomy。
message_intent为什么存在：这个 section 的认知任务。
structure_pattern如何组织：最核心的可复用结构形状。
layout_skeleton内容被如何组织和排列。
information_sequence信息阅读顺序，例如 headline → proof → CTA。
content_style媒体 / 素材策略，只是 modifier。
interaction_implication可见或暗示的交互模型。
design_language_modifier视觉语言气质，例如 dense-dashboard。
similarity_signature五个核心字段组成的稳定组合键。
discovery_note什么搜索意图应该命中它。
evidence / confidence至少 3 条可见证据，并标注置信度。

Pattern 组合演示区

这个区块不是产品功能，也不是让你手动给真实素材打标签。它用一组可点选的缩略图，模拟“一张 Eagle section 截图最终会被拆成哪些 Pattern 字段”。

1. 左侧是判断维度 每一组卡片代表一个核心签名字段，例如 section 类型、表达意图、结构形状、素材策略。
2. 点击卡片是在模拟一张截图 假设某张截图命中了这些选项，右侧就会把它们组合成一个模式签名。
3. 右侧结果用于校准命名 我们看组合后的 5 字段 signature 是否像一个可复用模式，而不是保存任何数据。

可以把这里理解成 Pattern 语法练习器：左边是词库，右边是把这些词拼成一句“这类 section 是什么模式”。真实 Eagle 分析时，这个组合会由 AI 根据截图证据写进备注；具体画面主角、截图细节和记忆点统一写进 evidence。

    Operating Rules

    这四条是后续调整框架时不要打破的核心原则。

    Evidence first.
    Pattern 判断必须先来自截图可见内容。
    Intent before material.
    先判断 message_intent，再判断 content_style。
    No false proof.
    不写转化更好、一定有效这类无数据结论。
    Evidence carries subjects.
    具体画面主角只进入 evidence，不进入核心相似聚类。
