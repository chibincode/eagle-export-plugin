# Daily Pattern Reviews

Create one file per analysis day:

```text
YYYY-MM-DD.md
```

Use the template at:

```text
docs/pattern-research/templates/daily-pattern-review.md
```

Daily reviews are append-only research notes. They should summarize what the agent saw that day and what should be compared against the registry.

Do not write daily reviews back to Eagle annotations. Eagle annotations remain per-image evidence; daily reviews are cross-image synthesis.
