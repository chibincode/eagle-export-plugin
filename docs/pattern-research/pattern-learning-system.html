System Layers

把每天的视觉分析拆成四层，避免单张截图 notes 和长期 pattern 混在一起。

Evidence

Image Evidence Layer

写回 Eagle annotation，只记录具体截图事实和 section-level Pattern Layer。

Daily

Daily Discovery Layer

每天生成跨截图复盘，记录重复信号、命名问题和人工 review 点。

Registry

Pattern Registry Layer

长期维护候选模式，不让每天的噪声直接变成正式 taxonomy。

Review

HTML Review Surface

用 HTML 展示样本墙、候选模式和变化，让讨论不被 markdown 表格拖慢。

Daily Review Contract

每天跑完 Eagle 分析后，新增一份 daily review，不直接修改正式 registry。

Daily review should include

  • category mix
  • repeated pattern signals
  • new observations
  • suggested registry updates
  • naming questions
  • manual review items

Registry should only change when

  • visible evidence is strong
  • the pattern repeats across samples
  • the name describes structure, not style
  • the pattern helps future Smart Discovery
  • the ambiguity is documented
